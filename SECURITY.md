# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.3.x   | :white_check_mark: |
| < 1.3   | :x:                |

## Reporting a Vulnerability

5tra83r Studios LLC. takes software security and developer safety seriously. If you believe you have discovered a vulnerability, security bypass, or credential exposure issue in ContextCut or any 5tra83r Studios software, please report it responsibly.

### How to Report

Please send an email to:
📧 **`security@5tra83rstudios.com`**

Include the following details:
1. Description of the vulnerability and potential impact.
2. Steps to reproduce the issue (proof of concept, code snippets, or environment details).
3. The specific ContextCut version or component affected.

### Our Commitment
* We will acknowledge receipt of your vulnerability report within **24 hours**.
* We will provide regular status updates every **48 hours** while the issue is being investigated and patched.
* We ask that you maintain mutual confidentiality and refrain from public disclosure until an official fix has been released.

Thank you for helping keep the developer ecosystem safe!
